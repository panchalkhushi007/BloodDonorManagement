# 🩸 Blood Donor Management System

A simple web-based Blood Donor Management System developed using HTML, CSS, and JavaScript.

## 📌 Project Description

The Blood Donor Management System is designed to manage blood donor information in an easy and organized way.

The system allows users to register donors, search donor records, view all donors, edit donor information, delete records, and check donor availability.

## 🎯 Objectives

- Register blood donor information
- Store donor details in the browser
- Search donors by Donor ID
- Search donors by Blood Group
- Display all registered donors
- Edit donor information
- Delete donor records
- Manage donor availability
- Provide a simple and user-friendly interface

## ✨ Features

- 🩸 Donor Registration
- 🔍 Donor Search
- 🧾 Donor Details
- ✏️ Edit Donor
- 🗑️ Delete Donor
- 🩸 Blood Group Filtering
- ✅ Donor Availability Status
- 💾 Local Storage
- 📱 Responsive Design
